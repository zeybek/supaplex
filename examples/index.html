@zeybek/supaplex examples

  • The game plays the 111 original levels with the keyboard or a gamepad.
  • Replays play the game's ten demos or a .SP file back, with pause, speed, and going back and forth.
  • Sprites draw the game from a sprite sheet.
  • The editor paints a level, tests it, proves it can be won and shares it.

Run npm run build first, because the examples load the package from dist/. The examples that run in Node and on a server are listed in the README.
